# Warehouse Inventory Management System

##  Project Overview
This project is a C++ console-based application built to automate and streamline warehouse inventory management. It was developed to replace manual stock tracking with a digital system capable of logging new items, updating quantities, and retrieving stock data efficiently. This project demonstrates practical application of object-oriented programming, control structures, and memory management in C++.

##  Core Features
* **Inventory Tracking:** Log new items into the system with unique identification numbers, names, and initial quantities.
* **Stock Updates:** Dynamically modify existing inventory levels to reflect incoming shipments or dispatched orders.
* **Data Retrieval:** Search the database and display current stock levels for specific items to maintain accurate inventory control.
* **Console Interface:** A clean, menu-driven user interface for easy navigation and operation.
